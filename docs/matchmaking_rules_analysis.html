副本匹配规则详细方案

信息源说明：本文档基于 2024-2025 年间各游戏最新版本（测试服/正式服）的公开机制整理。

核心参考：仗剑传说 (ZhangJian ChuanShuo / 雷霆竖屏放置)、魔兽世界 (WoW)、燕云十六声 (Where Winds Meet)、阿尔比恩 (Albion Online)。

1. 核心竞品机制总览

核心参考 (Core Reference)

1.1 仗剑传说 (ZhangJian ChuanShuo)

  • 定位：竖屏放置/卡牌RPG，强调轻量化社交与数值验证。
  • 匹配核心：“助战”与“职业互补”。作为放置类游戏，其匹配机制虽然弱化操作，但强调职业搭配（贤者/骑士优先），并引入AI助战解决等待问题。
  • 信息源：2025年公测版本及社区反馈（雷霆代理）。

辅助参考 (Auxiliary References)

1.2 魔兽世界 (WoW)

  • 定位：传统战法牧MMORPG。
  • 匹配核心：“职能匹配”与“动态等级”。通过地下城查找器 (LFG) 实现跨服、跨阵营匹配，严格遵循坦克/治疗/输出的铁三角架构。
  • 信息源：11.0 地心之战 (The War Within) 版本机制。

1.3 燕云十六声 (Where Winds Meet)

  • 定位：开放世界武侠，单人/多人模式并存。
  • 匹配核心：“主客机机制”与“无缝社交”。多人模式基于房主世界，强调小范围（2-5人）的沉浸式探索与话本攻坚，支持AI队友。
  • 信息源：2024年“仲吕测试”及后续测试版本。

1.4 阿尔比恩 (Albion Online)

  • 定位：沙盒MMORPG，装备驱动。
  • 匹配核心：“软性战力限制”与“低门槛竞技”。竞技场 (Arena) 和远征 (Expedition) 采用IP (Item Power) 软上限机制，拉平数值差距以保证体验。
  • 信息源：2024-2025年 Crystal Arena 赛季规则。

3. 核心竞品场景化匹配逻辑深度剖析

本节采用“核心机制 - 玩法模式 - 实际体验”的三层结构，对竞品进行深度拆解。

3.1 阿尔比恩 (Albion Online)

—— 装备驱动的硬核分层

一、 核心机制：没有“人物等级”，只有“装备强度” (IP)

首先要纠正一个概念： Albion 没有人物等级（Level 1-100） 。
取而代之的是 Item Power (IP，物品强度) 。你的强度完全取决于你穿了什么装备（Tier 4 到 Tier 8）以及你的技能专精（Spec）。
因此，匹配系统看的是你的 IP 和 角色定位（Tank/Healer/DPS） 。

二、 两种截然不同的“副本”模式

Albion 的 PVE 内容分为两类，匹配逻辑完全不同：

1. 远征（Expeditions）—— 类似于 WoW 的随机本
这是 Albion 中唯一有 自动匹配系统 的玩法，通常位于主城（Royal Cities）的蓝色传送门处。
  • 匹配规则：
    • 硬性 IP 门槛：比如 T6 远征（Hardcore Expedition, HCE 的前置），系统要求你至少有 1000 IP 才能点击匹配按钮。
    • 软性 IP 软顶（Soft Cap）：为了防止高装等玩家碾压低级远征，系统设有 IP 软上限 。比如在 T4 远征中，超过 1000 IP 的部分会被削减 80%。这保证了 T8 大佬进来打 T4 远征也不会像 WoW 那样一刀秒怪，依然需要按流程打。
    • 职能匹配：严格遵循 1坦克 + 1治疗 + 3输出 。
2. 随机地下城（Random Dungeons, RD）—— 真正的核心玩法
这是 Albion 玩家 99% 的 PVE 时间所在，位于野外（蓝区/黄区/红区/黑区）。
  • 注意：这类副本没有任何自动匹配系统！
  • 纯社交驱动 (LFG)：你想打 T8 蓝洞（Group Dungeon）？你必须在聊天频道（/lfg 频道）喊人：“T8 Map FF, LF Tank/Healer 1300+ IP”。或者你需要加入一个公会（Guild），在公会频道组队。
  • 没有系统帮你组队，你必须自己组齐 5-7 个人，然后一起骑马跑到洞口进去。
  • 跨度与门槛：
    • 完全由玩家决定：队长说“必须 1500 IP 才能进”，那你 1499 IP 都会被踢。队长说“带萌新，T4 平装随便来”，那你穿新手装也能进 T8 本。
    • 风险机制（红/黑区）：在高级区域打本，副本入口可能会被敌对阵营玩家入侵（Dive）。如果你们队伍里带了太多低 IP 萌新，会被敌对玩家杀人越货，装备全爆。
3. 高级玩法：HCE（硬核远征）
这是 Albion PVE 的终局玩法之一，位于主城，虽然有匹配入口，但 实际上全是预组队 。
  • 机制：使用高级地图（Map）开启的高难度副本，怪物伤害极高。
  • 匹配现状：理论上可以用系统匹配，但 实际上没人用 。因为 HCE 对装备和配合要求极高（通常要求 1600-1800+ IP，特定配装，特定跳怪路线）。如果你用随机匹配进去，大概率是因为队友乱引怪导致灭团修装备亏本。
  • 社区规则：HCE 玩家通过私聊频道（HCE Discord）组建固定队，严格筛选队友。

三、 体验总结：残酷的“不抱团就死”

  • 如果你是一个 T8（顶级） 玩家，想去打 T4（低级） 副本：
    • 普通远征（主城排队）：可以排，秒进。
      体验：你的属性被大幅压缩，打得比萌新快一点，但没法秒天秒地。你会觉得非常无聊，而且收益连修装备都不够。
    • 野外蓝洞（Group Dungeon）：没法排，得自己跑过去。
      体验：你可以一个人单刷（Solo）T4 的 5 人本。这时候没有系统压缩你的属性，你真的是一刀一群怪，非常爽，刷钱效率很高（很多高 IP 玩家会去蓝区单刷蓝洞赚钱）。
  • 社交性：Albion 强迫你社交。除了最低级的远征，所有高收益内容都需要你自己喊话组队、加公会、上 Discord 语音。它没有“点击就送”的匹配体验。

3.2 魔兽世界 (WoW)

—— 工业化的双轨制社交

一、 核心机制：装等 (Item Level) 与 职能 (Role)

WoW 的核心是 “战法牧”铁三角 和 装等门槛。所有匹配都基于这两个硬性指标。

二、 两种截然不同的“组队”模式

1. 地下城查找器 (Dungeon Finder / LFD) —— 自动化的快餐体验
  • 适用场景：升级路上的普通本、满级后的英雄本 (Heroic)、时空漫游。
  • 匹配规则：
    • 自动匹配：你选择职责（T/N/D），系统自动把你塞进一个跨服队伍。
    • 数值压缩：低级玩家和满级玩家可以排同一个本，系统会将所有人的数值动态调整到副本等级。
    • 社交体验：极度冷漠。进本说句“hi”，打完说句“gg”，全程可能没有任何交流。如果有人掉线，系统会像换电池一样秒补一个新人进来。
2. 预组队列表 (Premade Group Finder) —— 精英主义的简历模拟器
  • 适用场景：史诗钥石 (Mythic+)、团本 (Raid)、评级战场。
  • 匹配规则：
    • 手动申请：队长挂出钥匙“10层 仙林 来熟练工”，你申请加入。
    • 简历筛选 (Raider.IO)：系统虽然只显示装等，但玩家社区会使用插件 (Raider.IO) 查看你的“大秘境评分”和“通关记录”。
    • 残酷的门槛：如果你是 610 装等但没有分，申请 100 个队伍可能被拒绝 99 次。
    • 社交体验：高压且功利。为了过本，大家会进行战术沟通，但一旦失误（黑钥匙），队伍可能瞬间解散并伴随争吵。

三、 体验总结：效率至上的分裂社群

  • 新手/休闲玩家：活在 LFD 系统里，虽然能一直有本打，但永远体验不到核心乐趣，也交不到朋友。
  • 核心玩家：活在 Premade 系统里，每天像投简历一样申请进组，或者组建自己的“车队”（固定队）。
  • Beagle 启示：WoW 证明了 自动匹配 (Auto-Match) 极其高效但扼杀社交；手动组队 (LFG) 社交性强但门槛极高，容易劝退独狼。

3.3 仗剑传说 (ZhangJian ChuanShuo)

—— 放置类的数值验证

一、 核心机制：战力 (CP) 绝对主导，职业为辅

  • 战力门槛 (CP Threshold)：作为数值游戏，一切以 战力 (CP) 为核心。副本通常设有推荐战力，匹配系统首先筛选 CP 达标的玩家。
  • 职业互补 (Class Synergy)：虽然是放置，但高难本（如爬塔/传奇副本）存在 “战法牧”硬需求。
    • 骑士 (Knight)：必须要有，提供嘲讽与护盾，否则后排秒躺。
    • 贤者 (Sage)：必须要有，提供复活和续航。
    • 术士/斗士 (DPS)：提供输出。
    • 深度细节：纯 DPS 队伍在同战力下极易灭团，因此系统在匹配时会尝试（但不强制）凑齐铁三角。

二、 副本匹配模式：零等待的“自动流”

1. 自由匹配 (Free Match) —— 效率优先
  • 机制：点击“快速匹配”，系统在 跨服战区 (Battle Zone) 内寻找 CP 相近的玩家。
  • AI 填充 (Bot Fill)：这是其最核心的体验保障。
    • 触发条件：匹配时间超过 10-30秒 未组满。
    • AI 行为：系统生成与副本难度匹配的“机器人队友”。这些 AI 会自动使用标准技能循环，且通常数值略高于及格线，保证能过本。
    • 隐形规则：玩家往往分不清队友是真人还是 AI（除非看名字/公会），这降低了“鬼服”带来的焦虑感。
2. 队长带队 (Captain Mode) —— 针对性攻坚
  • 机制：队长建立房间，通过世界频道/公会频道喊话邀请。
  • 目的：为了应对 AI 无法处理的复杂机制（如特定集火、躲避），或者为了“拖尸”（带低战力小号）。
  • 匹配逻辑：战力总分匹配。系统会根据队伍的平均战力或总战力，匹配相应难度的动态敌人（或者进入固定难度的层级）。

三、 体验总结：无压力的“陪伴感”

  • 零社交压力：进本 -> 自动挂机 -> 领奖 -> 退出。全程无交流，甚至不知道队友是谁。
  • AI 的双刃剑：
    • 好：随时随地能打，不用求人。
    • 坏：极度削弱了人与人的链接。除了顶级高难本需要真人配合，90% 的时间玩家是在玩“单机”。
  • Beagle 启示：对于非硬核 MMO，“能打”比“和谁打”更重要。AI 填充解决了匹配的最痛点——等待。

4. Beagle 匹配规则与阶段性策略

基于用户体验的三个核心场景，结合《仗剑传说》的“战力区间匹配”逻辑，修正高战力玩家的跨服冲突问题。本规则分为两个阶段：特殊匹配（分线岛）与常规匹配（大世界）。

基础参数定义 (Basic Parameters) (点击收起/展开)
  • Player_CP (玩家战力)
    玩家当前的综合战斗力。
  • Dungeon_Min_CP (准入战力)
    副本允许进入的最低战力。
  • Dungeon_Cap_CP (碾压上限)
    系统判定的“正常开荒”战力上限（通常为推荐战力的 1.5倍 ~ 2倍）。
  • Server_Age (服务器天数)
    玩家所属服务器的开服天数。
  • Match_Pool (匹配池类型)
    Global_Pool (全服大池): 包含所有服务器的活跃玩家池。
    Local_Pool (本服小池): 仅包含本服务器玩家的独立池。

4.1 特殊匹配规则：分线岛时期 (Phase 1: Zone / Branch Island)

第一阶段：分线岛时期

此阶段玩家处于独立的 Zone (如 Zone 1001)，社交圈子严格限制在分线岛内，匹配池不会扩展至全服大池，仅在同批次服务器间扩散：

  • 1. 找本岛 (Local Zone)：P1 最优先。匹配本分线岛内的玩家。
  • 2. 同批次扩展 (Batch Expansion)：P2 其次。
    • 初级扩展：优先匹配服务器 ID 差值在 50 以内的同批次服务器。
    • 最终扩展：若仍未匹配成功，扩大到同批次（同一时间段开启）的所有服务器。

4.2 常规匹配规则：大世界时期 (Phase 2: Server / Big World)

第二阶段：大世界时期

此阶段匹配核心是 “跨服门禁” (The Gatekeeper) 机制：

  • 1. 本服优先：P1 最优先。总是先尝试在自己服务器（Home）寻找队友。
  • 2. 全服扩展 (Global Expansion)：P2 其次。
    • 进度检查 (Progress Check)：P0 硬性门槛。进入全服大池前，必须判定 服务器进度 (Server Era)。仅允许匹配 进度相近 (Diff < 7天) 的服务器，防止老服玩家碾压新服生态。
    • 战力保护：此规则适用于 所有场景 (Normal/Weak/Strong)，确保“同代人玩同代本”。

场景 1：正常均值战力玩家 (Normal)

用户画像
战力在副本推荐范围内，寻求正常游戏体验，不希望被拖累也不追求被秒带。
判定条件
Dungeon_Min_CP <= Player_CP <= Dungeon_Cap_CP
匹配规则流程：
阶段一
本服优先 (Local First)
  • 进入 Local_Pool (本服小池)。
  • 等待 10秒：寻找本服 CP 差异在 ±20% 内的队友。
阶段二
全服扩展 (Global Expansion)
  • 若 10秒 未匹配成功，触发 进度判定 (Check)。
  • 扩展至 Global_Pool (全服大池)，寻找 同进度 (Era-Consistent) 的合适队友。
阶段三
兜底 (Fallback)
  • 若总等待时间超过 30秒，填充 AI 队友。
体验目标：优先维系本服社交关系，其次保证匹配效率。

场景 2：低战力玩家 (Weak)

用户画像
战力低于推荐或刚达标，操作不熟练，希望有“大腿”带飞。
判定条件
Player_CP < Dungeon_Min_CP (若允许进入)。
匹配规则流程：
阶段一
本服求援 (Local Help)
  • 进入 Local_Pool。
  • 等待 15秒：优先寻找本服的高战玩家 (CP > Cap)。
阶段二
全服求援 (Global Help)
  • 触发 进度判定：仅向 同代服 发起求援。
  • 扩展至 Global_Pool，寻找全服的高战玩家 (避免老服数值怪)。
阶段三
正常/AI兜底
  • 若无高战，匹配正常玩家；最后由 AI 协助。
体验目标：优先让本服大佬带，增加本服膜拜感；实在没有再找跨服大佬。

场景 3：高战力玩家 (Strong)

用户画像
战力远超副本需求，目的是刷资源或快速通关。
痛点修正
防止跨服匹配到更老服务器的“巨佬”，导致本服第一变成跨服小弟。
判定条件: Player_CP > Dungeon_Cap_CP
匹配规则流程：
核心判定
进度一致性判定 (Progress Consistency)
  • 判定逻辑：比较 Server_Progress (服务器进度) 与 Dungeon_Era (副本进度)。
  • 进度超前 (Out-Era)：若服务器进度远超副本进度（如老服打新服保护期的副本），**无法进入 `Global_Pool`**。
  • 结果：被强制锁定在 Local_Pool。
筛选逻辑
本服筛选与隔离
  • 本服匹配：尝试在 Local_Pool 中寻找队友（高战或低战）。
  • 自然隔离：若本服无匹配对象（因为老服玩家不打低级本），则一直等待直到超时。
  • AI 兜底：超时后分配 AI 队友（单机体验）。
正常情况
当期体验 (In-Era)
  • 本服优先：优先匹配本服玩家。
  • 同届全服：若本服无人，扩展至 同批次服务器 (Same Batch)。
  • 老服屏蔽：绝对禁止 匹配到进度更前的老服玩家，避免“鸡头变凤尾”。
体验目标：**我是头部**。在物理上隔离了与新服玩家的接触，避免了数值碾压破坏新服生态，同时保证高战玩家随时有本打（虽然是打人机）。

4.3 补充规则体系 (Supplementary Rules)

1. 匹配优先级 (Priority)

Global_Pool 筛选权重顺序：
  1. 社交关系 (Social First)
    P0 邀请/预组队
    P1 公会成员 (Guild)
    P2 好友 (Friend)
  2. 职能互补 (Role Balance)
    优先匹配 骑士/贤者 (硬机制本)。
    (注：战力碾压队除外)
  3. 战力匹配 (CP Match)
    优先 CP ±10% 范围。
  4. 等待时长 (Wait Time)
    每5s 扩大5%范围。
    >30s 触发 AI 填充。

2. 社交转化 (Retention)

弱关系 -> 强关系转化机制：
  • 点赞/互粉 (Like System)
    结算弹窗
    同服路人显示[添加好友]按钮，一键发送请求。
  • 公会引流 (Guild Funnel)
    触发条件
    3人同公会 + 1路人 -> 通关后自动发公会邀请。

3. 惩罚与限制机制 (Penalties)

设计原则：软性引导为主，避免硬核劝退。
挂机/跳车 (AFK)
  • AI 接管：掉线/未操作自动跟随队长。
  • 收益衰减：托管状态掉落 -50%。
  • 冷却惩罚：日退队 >3次，CD 10分钟。
战力门槛 (Gate)
  • 硬门槛：CP < Min 禁止排队。
  • 软上限：高战进低本，属性压缩至 Cap (防抢怪)。

4. 跨服战力保护 (Chicken Head Protection)

🛡️
核心痛点：全服第一变小弟
Server 001 (100k战力) vs Server 010 (10k战力)。
若直接匹配，新服的大R玩家在老服玩家面前毫无存在感，严重挫伤付费体验。
解决方案：进度一致性判定 (Progress Consistency)
  • 新本保护期 (Protection Era)
    新副本解锁后的 X天内 (如30天)，仅允许 同进度 (In-Era) 服务器匹配。
    |Server_Progress - Dungeon_Unlock| <= Gap
  • 池子隔离 (Isolation)
    进度超前 (Out-Era) 的老服玩家被禁止进入 Global_Pool，强制分流至 Local_Pool (本服/AI)。
  • 追赶机制 (Catch-up)
    当新服世界等级/平均战力达到老服 90% 时，解除隔离。

4.4 规则总结表 (Rule Summary)

玩家状态 判定公式 匹配池归属 匹配对象范围 核心体验目标
正常 (Normal) Min <= CP <= Cap 全服大池 (Global_Pool) 全服同战力区间玩家 势均力敌，正常社交
低战 (Weak) CP < Min 全服大池 (Global_Pool) 优先高战 + 正常玩家 被带飞，顺利通关
高战 (Strong) CP > Cap 本服小池 (Local_Pool) 本服玩家 (极少) -> AI "我是头部" (无降维打击)
