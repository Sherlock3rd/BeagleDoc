# 七日版本社交渐进与地图玩法 CP 文档

## 1. 设计背景与现状
- 背景：7日版本需明确“每天玩家在社交上的状态与所玩内容”，并统一联盟关系的渐进方式（小队→联盟），避免从渗透社交到强对抗的断层。CEO 提出需要在七日版本中**验证 SLG 用户的转化率**，因此需**加入 SLG 玩法验证**，考察用户对更强对抗（阵营/联盟协作、场地竞争）的接受度与留存影响。
- 现状：Day1~2 在分线岛，以安全 PVE 与小队探索为主；Day2 晚解锁联盟；Day1 解锁五人小队副本（P0）与异步/离线助战（P1）；L1/L2 PVP 地块计划在 Day3 开启。
- 讨论范围：确定 GVE 地块开启时间与落位、确定外围 PVP 的承载目的（局部 PVP vs 联盟单位 GvG）、定义联盟社交从对抗到合作的过渡件与最小改动方案。

## 2. 设计目的
- 明确地图玩法的“渐进框架”，以联盟为友军集合，建立可复用的七日社交与战斗节奏。
- 以风险分层与分流工具（L1/L2）承接公共 PVP，避免过早引入领土政治与高惩罚。
- 在 7 日周期内逐步建立组织化协作认知，形成稳定的联盟社交闭环。
- 核心新增目的：确定“耐受度验证方案”，并对齐“耐受度映射的数据指标”，用于解释玩家在不同强度 SLG 内容下的参与、留存与流失阈值。

### 地块定义与结构（共识）
- PVE 地块：安全探索与资源产出区域，玩家自由进出，无对抗压力。
- PVP 地块（联盟单位，小中规模）：以联盟为单位的玩家对战区域；采用 AllianceID 友军免伤与跨盟红名判定；按 L1（常驻低风险）/L2（整点中风险短窗）分层，不承载领土政治，侧重热度与规则演练。
- GvG 地块（联盟单位，中大规模，独立场景）：以联盟为单位的更大规模对战场景；独立地块与规则集，强调组织化与场景设计（占点/旗帜/评分/整点）；早期以“预演地块”为主（短窗、荣誉/装饰为主），避免过早绑定数值通道与领土政治。
- GVE 地块（特殊结构）：
  - 核心定位：多人协作挑战与进阶资源产出区域。
  - 结构共识：包含内外两圈结构（外圆 GvG 用于争取内圆 GVE 准入），此物理结构在所有 CP 方案中均存在，但各方案对双圈的开启方式与预期体验有所不同。
  - 地块连接：连接到常规 PVE 地块（安全主干道与周边探索）。

## 3. CP 方案总览（按改动 Scope 重新划分）
- CP1（最大 Scope）：把目前的 GVE 玩法降级为一个纯粹的 GVE 玩法，作为后面新增的正式 GvG 玩法的前置渐进。
- CP2（中等 Scope）：保留目前 GVE 地块中外圈的 GvG 属性，并将其作为核心验证，但是在前一步增加一个新的 GVE 玩法做渐进。
- CP3（最小 Scope）：保留目前 GVE 地块中外圈的 GvG 属性，并将其作为核心验证，只是分割内外圈开启时间来实现社交协作峰值的渐进。
- 统一约束：CP1 与 CP2 都不拆分已有 GVE 地块玩法解锁。
- 对标口径：CP 内“城镇 PVE/城镇 PVP”主要对标《三谋》的城镇玩法；仅 CP1 中 GvG 地块的扩展争夺玩法可参考 RoK/CoD 的领土争夺模块。

## 4. CP1（最大 Scope：完整七日规划 + 城镇争夺 GvG）
### 4.1 一句话玩家体验
- 从 Day3 开始快速进入“联盟组织化作战”，在完整七日节奏中体验“对抗夺点—协作产出—联盟成长”的强目标闭环。

### 4.2 耐受度映射指标
  | 映射维度 | 指标口径 | 耐受度判定 |
  | :--- | :--- | :--- |
  | **强对抗耐受** | 城镇争夺 GvG 到场率、连续参与场次、人均战斗时长 | 判断玩家对高压联盟对抗的可持续承受阈值。 |
  | **强协作耐受** | GVE 到场率/完成率、联盟内分工覆盖率 | 判断玩家对高组织成本协作链路的接受度。 |
  | **转化耐受** | SLG 元素参与率（攻城、驻防、集结指令响应）、7 日留存（7留） | 判断“高强度 SLG 导入”是否造成转化提升或流失放大。 |
  | **情绪耐受** | 失败后次日回流率、负反馈关键词占比 | 判断高压失败体验对留存心智的冲击。 |

### 4.3 新增内容 Scope

> **新增玩法模块**
> - 新增“城镇争夺型 GvG”、“特殊争夺点 GvG”或“领土”玩法模块（联盟单位争夺）。
> - 对标参考：城镇 PVE/PVP 主要对标参考《三谋》的城镇玩法；领土/特殊点争夺主要对标参考 Rise of Kingdoms、Call of Dragons 的领土争夺模块。
> 
> **已有内容修改**
> - GVE 地块需改为纯 GVE 区域，不再具备 PVP 属性；作为前置的联盟协作玩法存在，承担联盟协作的渐进功能。

### 4.4 渐进体验轴（时间轴）
  - Day1-2 个人探索
  - Day2 晚 进入联盟
  - Day3 合作行动（GVE 首轮，无争夺性）
  - Day4 合作行动（GVE 继续推进，为后续 GvG 积累资源与阵地）
  - Day5-7 城镇争夺 GvG 开启（维持高位强社交）

> **设计注释**：把目前的 GVE 玩法降级为一个纯粹的 GVE 玩法，作为后面新增的正式 GvG 玩法的前置渐进。

### 4.5 方案优缺点评估
  | 评估维度 | 具体表现 |
  | :--- | :--- |
  | **优势 (Pros)** | 验证最完整、最准确，可同时覆盖 7 留、SLG 参与率、联盟组织化上限。 |
  | **劣势 (Cons)** | 开发与调参成本最高，对泛用户承压要求高，防流失机制依赖更强。 |

## 5. CP2（中等 Scope：现有内容 + 联盟攻城前置强协作）
### 5.1 一句话玩家体验
- 在不重做主链路的前提下，先经历一次“联盟协作攻城并迁城”的强协作事件，再进入 GVE 解锁阶段。

### 5.2 耐受度映射指标
  | 映射维度 | 指标口径 | 耐受度判定 |
  | :--- | :--- | :--- |
  | **协作耐受** | 联盟攻城集结成功率、攻城参与深度、迁城执行率 | 判断玩家是否能接受前置高协作门槛。 |
  | **SLG 参与耐受** | 攻城后 SLG 内容参与率、联盟目标跟随率 | 判断“先强协作再解锁”是否提升 SLG 参与黏性。 |
  | **节奏耐受** | 攻城触发后流失率、次日回流率 | 判断前置强协作是否造成节奏断层或挫败。 |

### 5.3 新增内容 Scope

> **新增玩法模块**
> - 新增前置 GVE 玩法模块：例如 <span style="color:red; font-weight:bold;">联盟攻城、温泉战斗、联盟 Boss</span> 等。
> - 对标参考：前置 GVE 玩法主要参考 RoK、WOS 等游戏中的联盟玩法；城镇攻防相关可参考《三谋》。
> 
> **已有内容修改**
> - 内外圈拆分分批次开启，外圈 GvG 先开启，并且外圈场地需要承载 GvG 属性。
> - PVP L2 地块要增加联盟对抗的动机，需要修改并调整投放内容。

### 5.4 渐进体验轴（时间轴）
  - Day1-2 个人探索
  - Day2 晚 进入联盟
  - Day3 GVE 玩法筹备
  - Day4 GVE 玩法（联盟协作组织，对抗强度中等）
  - Day5 外圈 GvG 开启（强对抗，验证 GvG 接受度）
  - Day6-7 内圈 GVE 开启（达到社交协作峰值）

> **设计注释**：保留目前 GVE 地块中外圈的 GvG 属性，并将其作为核心验证，但是在前一步增加一个新的 GVE 玩法做渐进。

### 5.5 方案优缺点评估
  | 评估维度 | 具体表现 |
  | :--- | :--- |
  | **优势 (Pros)** | 在现有框架上较快落地，能更早验证联盟强社交生态与 SLG 参与拉升。 |
  | **劣势 (Cons)** | 攻城节点若反馈不佳会影响后续 GVE 体验，需精控奖励与门槛。 |

## 6. CP3（最小 Scope：保持现有内容的分段递进）
### 6.1 一句话玩家体验
- 先练习、再准入、后爆发，按 Day3→Day4→Day5 的分段节奏平滑进入强协作内容。

### 6.2 耐受度映射指标
  | 映射维度 | 指标口径 | 耐受度判定 |
  | :--- | :--- | :--- |
  | **练习段耐受** | Day3 L1/L2 参与率、首战完成率 | 判断低门槛 PVP 练习是否有效降低后续门槛。 |
  | **准入段耐受** | Day4 外圆 GvG 到场率、败退后回流率 | 判断中压对抗阶段的可接受区间。 |
  | **爆发段耐受** | Day5 内圆 GVE 到场率/完成率、SLG 元素参与率 | 判断递进节奏是否成功导入核心 SLG 行为。 |

### 6.3 新增内容 Scope

> **新增玩法模块**
> - 无新增核心系统，延续现有 CP-B 框架与节奏拆分。
> - 对标参考：分层风险区递进主要对标参考 Albion Online；分层组队内容过渡主要对标参考 World of Warcraft。
> 
> **已有内容修改**
> - 内外圈拆分分批次开启，外圈 GvG 先开启，并且外圈场地需要承载 GvG 属性。

### 6.4 渐进体验轴（时间轴）
  - Day1-2 个人探索
  - Day2 晚 进入联盟
  - Day3 L1/L2 练习
  - Day4 外圆 GvG 准入
  - Day5 内圆 GVE 爆发

> **设计注释**：保留目前 GVE 地块中外圈的 GvG 属性，并将其作为核心验证，只是分割内外圈开启时间来实现社交协作峰值的渐进。

### 6.5 方案优缺点评估
  | 评估维度 | 具体表现 |
  | :--- | :--- |
  | **优势 (Pros)** | 改动最小、风险最低、最快形成可观测样本，适合快速迭代。 |
  | **劣势 (Cons)** | 验证深度有限，对“高强度 SLG 耐受上限”的覆盖不如 CP1/CP2。 |

## 7. 对比与总结

### 7.1 方案横向对比

| 方案 | 投入定位 | 核心新增机制 | 验证侧重点 | GVE 地块设定 |
| :--- | :--- | :--- | :--- | :--- |
| **CP1** | 高投入 / 高回报 | 城镇争夺 GvG + 联盟进程规划 | **全局 SLG 生态验证**（高压对抗下的 7 留与组织化上限） | 纯联盟协作目标区（物理双圈合并视为整体） |
| **CP2** | 中投入 / 强验证 | 联盟攻城 + 占城迁城闭环 | **前置强协作验证**（攻城集体行动对后续 GVE 黏性的拉升） | 保留内外圈分割（外圈 GvG 先开启验证） |
| **CP3** | 低投入 / 稳节奏 | 无新增核心系统，强化阶段引导 | **平滑过渡验证**（渐进式保护节奏对泛用户的效果） | 分离解锁结构（外圈 GvG 争取内圈 GVE 准入） |

### 7.2 总结与共识约束

**核心观测指标共识**
无论最终选择哪个方案，以下数据口径是必须统一追踪的底线：
1. **商业/留存底线**：7 日留存率（7留）与次日回流率。
2. **玩法转化率**：SLG 元素参与率（到场、集结、攻城等动作）。
3. **耐受度解释**：结合各方案专属的“耐受度映射指标”（如连败后流失、分工覆盖率），来解释核心指标的波动原因。

**地块与解锁规则约束**
- **GVE 结构差异**：物理结构上均为内外双圈。但在体验预期上：CP1 将双圈合并视为纯粹的联盟协作整体，弱化甚至不体现外圈的阻挡与对抗概念；CP2 和 CP3 保留明确的内外圈分割，外圈具备 GvG 属性并先于内圈 GVE 开启，作为对抗验证或准入门槛。
- **解锁策略底线**：所有方案均不拆分现有 GVE 地块的底层解锁逻辑，新增的对抗或协作玩法仅作为“外挂式增强”或“前置门禁”。

## 8. CP 发散方法总结（补充规范）
- 维度统一：每个 CP 固定包含五件套——一句话体验、耐受度映射指标、新增内容 Scope、渐进体验轴、优缺点评估。
- Scope 先行：优先按改动范围划分 CP，再定义验证目标，避免“节奏命名”和“研发成本”错位。
- 指标闭环：核心聚焦 7 留与 SLG 参与率，并以耐受度映射解释高压节点的流失与回流。
- 共识约束：涉及 GVE 地块解锁策略的既有逻辑保持不拆分，新增内容只做外挂式增强。
