# 七日版本社交渐进与地图玩法 CP 文档

## 1. 设计背景与现状
- 背景：7日版本需明确“每天玩家在社交上的状态与所玩内容”，并统一联盟关系的渐进方式（小队→联盟），避免从渗透社交到强对抗的断层。CEO 提出需要在七日版本中**验证 SLG 用户的转化率**，因此需**加入 SLG 玩法验证**，考察用户对更强对抗（阵营/联盟协作、场地竞争）的接受度与留存影响。
- 现状：Day1~2 在分线岛，以安全 PVE 与小队探索为主；Day2 晚解锁联盟；Day1 解锁五人小队副本（P0）与异步/离线助战（P1）；L1/L2 PVP 地块计划在 Day3 开启。
- 讨论范围：确定 GVE 地块开启时间与落位、确定外围 PVP 的承载目的（局部 PVP vs 联盟单位 GvG）、定义联盟社交从对抗到合作的过渡件与最小改动方案。

## 2. 设计目的
- 明确地图玩法的“渐进框架”，以联盟为友军集合，建立“环外对抗热度→环内合作峰值”的可复用节奏。
- 以风险分层与分流工具（L1/L2）承接公共 PVP，避免过早引入领土政治与高惩罚。
- 在 7 日周期内逐步建立组织化协作认知，形成稳定的联盟社交闭环。

### 地块定义与结构（共识）
- PVE 地块：安全探索与资源产出区域，玩家自由进出，无对抗压力。
- PVP 地块（联盟单位，小中规模）：以联盟为单位的玩家对战区域；采用 AllianceID 友军免伤与跨盟红名判定；按 L1（常驻低风险）/L2（整点中风险短窗）分层，不承载领土政治，侧重热度与规则演练。
- GvG 地块（联盟单位，中大规模，独立场景）：以联盟为单位的更大规模对战场景；独立地块与规则集，强调组织化与场景设计（占点/旗帜/评分/整点）；早期以“预演地块”为主（短窗、荣誉/装饰为主），避免过早绑定数值通道与领土政治。
- GVE 地块（特殊环状结构）：由内外两圈构成
  - 内圆：GVE 玩法真实区域（多人协作挑战与进阶资源产出）
  - 外圆：GvG 战斗区域，用于“通过战斗或社交协商”来决定内圆体验与资源分配
  - 地块连接：外圆会连接到常规 PVE 地块（安全主干道与周边探索）
  - 目的：以“外圆 GvG → 内圆 GVE”的结构，允许玩家通过战斗或社交来决定内圆的游玩与分配

## 3. CP 方案总览（三种完整路径）
- 总览说明：以下第 4/5/6 章分别为三套“完整且独立”的执行方案（快转/慢转/佛系转），每章均含目标与验证点、时间线与落位、机制与承载、UI 引导、指标与观测、风险与保护、区域参数、优缺点。

## 4. CP-A 快转（Day3 快转启动，Day4 协作峰值）
- 目标与验证点：
  - 目标：在 Day3 快速形成“联盟组织化 + 对抗热度”，并在 Day4 形成协作峰值；Day5-7 持续外圆 GvG 与内圆 GVE 轮转验证，尽早验证 SLG 接受度与转化率。
  - 验证点：Day3-5 联盟活跃曲线、整点到场率、内圆 GVE 到场/完成率、对抗→协作转换率、回流率、次日留存。
- 时间线与落位：
  | 时间节点 | 开启玩法与系统 | 落位与体验说明 |
  | :--- | :--- | :--- |
  | **Day3** | L1 常驻 + L2 整点；GVE 外圆开放 | 外圆连接 PVE 并承载 GvG 准入战。先做组织化与准入筛选，不在 Day3 完成内圆协作峰值。 |
  | **Day4** | 开放内圆 GVE 首轮窗口 | Day4 进入“外圆 GvG → 内圆 GVE”主链路，并形成协作峰值。 |
  | **Day5-7** | 夜间 L2 高压窗 + 日间内圆 GVE 多轮 | 不做独立 GvG；Day5-7 持续进行外圆 GvG 与内圆 GVE 多轮轮转，承接 Day4 峰值并验证对抗→协作转换。 |
- 玩家体验与社交渐进：
  | 社交维度 | 体验演进说明 |
  | :--- | :--- |
  | **熟人 → 生人** | Day1-2 熟人小队为主；Day3 起在外圆 GvG 与 Day4 后的内圆 GVE 中进行混合协作。 |
  | **渗透 → 隔离** | 公共 PVP 采用联盟单位隔离判定；内圆 GVE 熟人协作，外圆以隔离保障秩序。 |
  | **关键感受** | 强势转折带来身份认同；对抗情绪在环外释放，合作成就在环内兑现。 |
- 渐进体验轴（时间轴）：
  - Day1-2 个人
  - Day2 晚 进入联盟
  - Day3 联盟目标形成（广播/目标板）+ 外圆 GvG 准入战
  - Day4 合作行动（内圆 GVE 首轮）
  - Day5-7 合作对抗（L1/L2/外圆 GvG 高压窗）+ 内圆多轮协作
- 玩法与系统节点：
  - Day1-2：小队副本与异步/离线助战；安全 PVE；分线岛
  - Day2 晚：联盟开放与频道引导；友军规则预告（SquadID→AllianceID）
  - Day3：GVE 地块启用“外圆连接 PVE + 外圆 GvG”；整点广播；外圆 GvG 联盟判定
  - Day4：开放内圆 GVE 首轮；轻协作任务（护送/占点助推/清障）；目标板引导分工
  - Day5-7：L2 热点与跨小队协作；外圆 GvG 与内圆 GVE 多轮轮转
- SLG 过渡要素（RoK 参考）：
  - Day3 联盟 Boss Rally（集结打洛哈）：在外圆 GvG 外侧集合，完成后发放联盟荣誉/装饰，用作“合作组织化”入口
  - 联盟活动：每日/周联盟任务与建设进度，绑定 GVE 完成与频道参与，形成“目标→行动”的闭环
- 对标参考与分享：
  - Albion Online（早期公会协作+ZvZ），Call of Dragons（联盟 Rally 与大型事件双峰），World of Warcraft（副本/战场并行），Rise of Kingdoms（联盟 Boss Rally 与活动过渡）
  - 注：为“部分映射”，不存在完整 7 日并发的 1:1 对标，属强节奏组合创新。
- 指标与观测：
  | 指标维度 | 观测内容 | 核心目的 |
  | :--- | :--- | :--- |
  | **参与度** | PVP/GVE 到场率、完成率 | 评估高压强协作玩法的直接吸引力。 |
  | **社交生态** | 频道活跃与跨小队协作比、团队分工稳定度 | 验证从熟人渗透到生人隔离的社交网络健康度。 |
  | **留存反馈** | 留存率与回流率 | 观测高压对抗环境下的泛用户承压极限。 |
- 风险与保护/区域参数：
  - 泛用户保护：安全主干道、近点回流、快速复活；KR 区降低 L2 频率与奖励强度；US 区按建议频率。
- 优缺点：
  | 评估维度 | 具体表现 |
  | :--- | :--- |
  | **优势 (Pros)** | 尽早检验强协作与阵营接受度；快速形成活动高峰节奏。 |
  | **劣势 (Cons)** | 泛用户承压较大，容易产生流失，需强依赖引导与保护机制。 |

## 5. CP-B 慢转（Day3 以 L1/L2 为主，Day4 开外圆，Day5 开内圆）
- 目标与验证点：
  - 目标：以自发组织为核心，逐步提升对抗强度；Day4 验证外圆 GvG 组织能力，Day5 验证内圆 GVE 协作接受度。
  - 验证点：Day3-5 频道活跃与跨小队协作、L1/L2 完成率、Day4 外圆 GvG 到场率、Day5 内圆 GVE 完成率与留存。
- 时间线与落位：
  | 时间节点 | 开启玩法与系统 | 落位与体验说明 |
  | :--- | :--- | :--- |
  | **Day3** | L1/L2 常驻与整点 | 以公共 PVP 地块体验为主，形成联盟组队与基础对抗节奏；GVE 区域不开放。 |
  | **Day4** | 开放 GVE 外圆 GvG 场地 | 先在外圆完成联盟对抗与准入筛选，验证组织度与集结效率。 |
  | **Day5** | 开放 GVE 内圆玩法 + 独立 GvG 预演 | 在外圆对抗基础上进入内圆协作，形成“先对抗后协作”的主峰体验。 |
- 玩家体验与社交渐进：
  | 社交维度 | 体验演进说明 |
  | :--- | :--- |
  | **熟人 → 生人** | Day3 先在 L1/L2 完成频道聚拢；Day4 在外圆 GvG 形成跨队协同；Day5 内圆 GVE 达成协作峰值。 |
  | **渗透 → 隔离** | Day4 起在外圆 GvG 引入更强隔离；Day5 内圆 GVE 固化分工；外圆连接 PVE 保证回流安全。 |
  | **关键感受** | 从“我和我的小队”逐步过渡到“我们这个联盟”，节奏温和，压力递进。 |
- 渐进体验轴（时间轴）：
  - Day1-2 个人
  - Day2 晚 进入联盟
  - Day4 联盟目标形成（活动公告/广播）+ 外圆 GvG 准入战
  - Day5 合作行动（PVE 轻协作/内圆 GVE）
  - Day4-5 合作对抗（小规模 PVP：L1/L2/外圆 GvG）
  - Day5 联盟对抗（独立 GvG 预演）
- 玩法与系统节点：
  - Day3：开 L1/L2 与联盟免伤判定；频道引导与集合点提示
  - Day4：开放 GVE 外圆 GvG；轻协作任务密度提升；联盟目标形成（活动公告/广播）
  - Day5：开放 GVE 内圆 GVE；目标板与团队分工；独立 GvG 预演地块（占点/旗帜/评分最小集）
- SLG 过渡要素（RoK 参考）：
  - Day4 联盟 Boss Rally：集结在 GVE 外圆外侧，完成后提升联盟荣誉/装饰与目标热度
  - 联盟活动周任务：绑定 Day4 外圆 GvG 与 Day5 内圆 GVE，到场与完成计入联盟进度条
- 对标参考与分享：
  - Albion Online（黄/红区渐进冲突，自发组织明显），燕云十六声（主世界状态与阶段性活动），Rise of Kingdoms（联盟 Boss Rally 与活动过渡）
  - 注：Day3 仅 L1/L2、Day4 外圆 GvG、Day5 内圆 GVE 的三段式节奏少有直接对标，属递进协作组合。
- 指标与观测：
  | 指标维度 | 观测内容 | 核心目的 |
  | :--- | :--- | :--- |
  | **组织能力** | 自发组织指数（非系统邀约的集合度） | 验证慢转节奏下玩家自主建立协作网络的能力。 |
  | **参与度** | Day4 外圆到场率、Day5 内圆完成率、协作参与比 | 评估分段开启后玩家的实际参与意愿。 |
  | **留存反馈** | 转折日（Day5）回流率与留存变化 | 观测节奏突变时泛用户的流失情况。 |
- 风险与保护/区域参数：
  - 泛用户保护优先级更高；KR 区进一步降低 L2 奖励强度；US 区保持节奏。
- 优缺点：
  | 评估维度 | 具体表现 |
  | :--- | :--- |
  | **优势 (Pros)** | 自组织自然，压力递进；更贴近弱社交的大盘。 |
  | **劣势 (Cons)** | 协作峰值成形晚，早期热度可能不足。 |

## 6. CP-C 特别慢佛系转（Day6 同步开内外圆，前置禁入+迷雾）
- 目标与验证点：
  - 目标：最大化保护泛用户与佛系用户，在低压节奏中验证协作接受度与留存。
  - 验证点：前 5 天低压留存、联盟自组织形成度、Day6 到场与完成率、佛系用户协作接受度。
- 时间线与落位：
  | 时间节点 | 开启玩法与系统 | 落位与体验说明 |
  | :--- | :--- | :--- |
  | **Day3-5** | L1/L2 低频 + GVE 区域禁入 | GVE 内外圆全部关闭并加迷雾遮挡，不提供进入与观战；仅保留低压公共玩法。 |
  | **Day6** | GVE 内外圆同步开放 | 外圆 GvG 与内圆 GVE 同时开启，不做前后层级区分，集中验证晚开强协作接受度。 |
- 玩家体验与社交渐进：
  | 社交维度 | 体验演进说明 |
  | :--- | :--- |
  | **熟人 → 生人** | 前 5 天以熟人小队与轻量生人协作为主；Day6 同步开内外圆后快速进入团队协作。 |
  | **渗透 → 隔离** | 前期保持渗透社交；Day6 同步开放后一次性引入隔离规则，外圆连接 PVE 保障回流安全。 |
  | **关键感受** | 低压与可控，强调“我也能贡献”的协作体验与情绪正反馈。 |
- 渐进体验轴（时间轴）：
  - Day1-2 个人
  - Day2 晚 进入联盟
  - Day5 联盟目标形成（频道集合/目标板）
  - Day3-5 合作行动（PVE 轻协作）
  - Day3-5 合作对抗（小规模 PVP：L1/L2 低频）
  - Day6 联盟对抗（不启独立 GvG；内外圆同步开放）
- 玩法与系统节点：
  - Day3-5：护送/占点助推/清障等轻协作；频道提示与集合；L1/L2 低频热点；GVE 区域迷雾遮挡与禁入
  - Day6：GVE 内外圆同步启用；目标板与团队分工简化版；不区分先后层级
- SLG 过渡要素（RoK 参考）：
  - Day6 联盟 Boss Rally（低压版，可选参与）：以社交参与与可视化进度为主，奖励适中
  - 联盟活动：以社交参与与轻任务为主，不引入强惩罚
- 对标参考与分享：
  - Sky 光·遇（低压社交协作）、Pokemon GO（社区日弱社交与低压参与），Rise of Kingdoms（联盟 Boss Rally 与活动过渡）
  - 注：Day6 才同步开放内外圆的节奏无直接对标，样本可能不足，需要以迷雾揭示与奖励可见性保障到场与完成。
- 指标与观测：
  | 指标维度 | 观测内容 | 核心目的 |
  | :--- | :--- | :--- |
  | **留存反馈** | 低压留存、情绪反馈（弃游原因采样） | 验证最佛系节奏下的大盘留存与用户核心痛点。 |
  | **参与度** | 协作参与比、到场与完成率 | 观测极度滞后的强协作玩法是否仍具吸引力。 |
- 风险与保护/区域参数：
  - 强化保护策略；KR 区进一步降低 L2 频率；US 区维持中性节奏。
- 优缺点：
  | 评估维度 | 具体表现 |
  | :--- | :--- |
  | **优势 (Pros)** | 最低压验证，提升好感与泛用户留存。 |
  | **劣势 (Cons)** | 强协作与阵营接受度样本不足，验证滞后。 |

## 7. 对比与总结
- 局部 PVP vs 联盟单位 GvG：局部 PVP在环外承载“筛选/热度/规则演练”，GvG独立地块承载“政治/领土/荣誉”，避免过早绑死数值通道。
- 渐进一致性：自 Day3 起持续灌输联盟友军规则，以减少从渗透社交到更强对抗的认知断层。
 - 归纳：三条路径分别覆盖强压并行验证、递进验证、低压延后验证，满足 CEO 的 SLG 转化率与接受度多角度抽样需求。

## 8. CP 发散方法总结（补充规范）
 - 体验维度：以“转化速度”为轴，至少给出快转/慢转/佛系转三条完整路径，各自明确时间锚点与强度。
 - 风险与承受：在每条路径下明确风险分层与泛用户保护策略，避免单一节奏压垮大多数用户。
 - 组织化入口：明确从自发组织到频道分工的转化节点（广播、入口提示、轻协作任务）。
 - 指标闭环：为每条路径设定可观测的 SLG 接受度指标（到场率、完成率、协作参与度、留存/回流）。
 - 区域差异：针对不同地区（如 KR/US）设定参数化窗口（L2 频率、奖励强度）。
