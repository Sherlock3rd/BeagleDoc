🚀 玩家进入游戏流程 (COMIC EDITION)

💥 注意!

本设计严格遵循 Scheme 2 核心规则：新玩家基于物理区域 (Region) 分配 Zone，老玩家选择服务器 (Server) 后再选区域。

graph TD Start((开始)) --> Launch[启动游戏] Launch --> SDK[SDK 初始化/登录] SDK --> NetCheck{网络检测} NetCheck -- 失败 --> Error[显示错误弹窗] NetCheck -- 成功 --> AccountCheck{是否有账号?} AccountCheck -- 否 --> NewPlayerFlow[新玩家流程] AccountCheck -- 是 --> OldPlayerFlow[老玩家流程] subgraph New_Player [新玩家旅程] NewPlayerFlow --> ShowMap[展示世界地图 scheme2_map_v3] ShowMap --> SelectRegion[选择物理区域 A/B/C/D] SelectRegion --> AssignZone[系统分配至对应 Zone] AssignZone --> CreateChar[创建角色] CreateChar --> EnterGame end subgraph Old_Player [老玩家旅程] OldPlayerFlow --> ShowLastChar[展示上次登录角色] ShowLastChar --> Action{玩家操作} Action -- 直接开始 --> EnterGame[进入游戏] Action -- 切换服务器 --> ServerList[展示服务器列表] ServerList --> SelectServer[选定服务器] SelectServer --> SelectRegionOld[选择出生区域] SelectRegionOld --> EnterGame end
