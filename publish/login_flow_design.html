2. 详细流程说明 (Detailed Steps)

2.1 游戏启动与检测 (Startup & Check)

  • 游戏启动: 客户端冷启动。
  • SDK检测: 初始化渠道SDK，检查强制更新。
  • 网络检测: Ping Login Server 网关，选择延迟最低节点。

2.2 账号登陆 (Account Login)

  • Token 检查与自动登录: 启动时优先检查本地 Token。若有效则直接静默登录，跳过登陆界面；若无效则显示登陆界面。
  • 手动登录: 唤起 SDK 登录窗口或输入账号密码。
  • 获取数据: 登录成功后，从服务器拉取该账号下的最近登录角色、拥有角色的服务器列表以及推荐服务器列表。

2.3 开始游戏/切换 (Lobby & Selection)

这是玩家进入游戏前的核心决策界面。

A. 默认展示 (Default View)

  • 已有角色玩家: 登陆屏默认展示上次登录的角色 (Last Played)。
    • 开始游戏: 直接进入游戏世界。
    • 切换/总览: 点击进入角色总览界面，选择其他已有角色或创建新角色。
  • 无角色玩家 (新账号): 默认直接进入角色总览/新建界面，引导创建新角色。

2.4 角色定制与进入游戏 (Character Creation & Entry)

进入游戏流程分为两条独立的逻辑通道：新角色完成创建后出生在新手村，老角色直接恢复至上次下线时的场景。

TRACK 1: NEW JOURNEY (新角色)

逻辑流程： 连接服务器 (Connect) -> 角色定制 (Customize) -> 出生在新手村 (Spawn)。

流程说明

  • Track 1 (新角色): 完成捏脸定制后，系统生成新角色数据，并将角色生成在预设的“新手村”出生点。
  • Track 2 (老角色): 略过定制环节，直接读取存档数据，将角色恢复至上次下线时所在的坐标和场景。

3. 异常处理 (Exception Handling)

异常场景 处理逻辑
SDK 初始化失败 弹窗提示“组件初始化失败”，禁止进入下一步，提供退出或重试按钮。
网络超时 在登录或连接阶段超过 10s 无响应，提示“连接服务器超时，请检查网络”。
服务器维护 在选择服务器或点击开始游戏时，若目标服处于维护状态，弹窗显示维护公告及预计开服时间。
排队等待 若目标服务器负载过高，弹出排队窗口，显示当前排队位置及预计等待时间。
